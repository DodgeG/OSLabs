# OSLabs

## 项目简介

OSLabs 是浙江大学操作系统课程（RISC-V 64）实验项目仓库。项目以“从零搭建一个简化内核”为主线，覆盖了从启动引导到用户态支持的关键路径，重点训练对操作系统底层机制的理解与实现能力。

相比仅完成实验步骤，本仓库同时保留了各阶段实验文档与实现代码，方便按实验脉络回溯设计思路、对照关键代码和复现实验结果。

## 项目架构

项目采用“按实验阶段递进”的架构组织方式：

- `lab1`：完成内核入口与基础启动流程
- `lab2`：建立 trap 处理与时钟中断机制
- `lab3`：引入线程与调度策略，实现上下文切换
- `lab4`：实现页表与虚拟内存映射（SV39）
- `lab5`：支持用户态程序、系统调用和内核态/用户态切换

通用运行架构在各 lab 中基本一致：

- 构建层：`Makefile` + RISC-V 交叉编译工具链
- 内核层：`arch/riscv` 下的启动、异常、中断、内存和进程相关代码
- 运行层：QEMU 启动内核镜像，必要时用 GDB 联调

## 实验内容

- Lab 0: GDB + QEMU 调试 64 位 RISC-V Linux
- Lab 1: RV64 内核引导
- Lab 2: RV64 时钟中断处理
- Lab 3: RV64 内核线程调度
- Lab 4: RV64 虚拟内存管理
- Lab 5: RV64 用户态程序

## 仓库结构

- `lab1` ~ `lab5`: 各实验代码目录（每个目录有独立 `Makefile`）
- `Lab 0 ...md` ~ `Lab 5 ...md`: 各实验报告/说明文档

## 环境依赖

- Linux / WSL2（推荐 Ubuntu）
- `riscv64-linux-gnu-gcc`（交叉编译工具链）
- `qemu-system-riscv64`
- `make` / `gdb`

## 快速运行

以 Lab2 为例：

```bash
cd lab2/lab2
make run
```

以 Lab5 为例：

```bash
cd lab5/lab5
make run
```

调试模式（QEMU 启动后等待 GDB）：

```bash
make debug
```

## 说明

- 各实验目录互相独立，请进入对应目录编译运行。
- 实验细节、实现思路和截图见根目录的 `Lab *.md` 文档。
